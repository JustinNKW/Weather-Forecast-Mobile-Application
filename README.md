# Weather Forecast Mobile Application

## About the App

This is a mobile application that provides weather information for locations across Singapore by utilizing a weather API.

### Main Features

- Weather forecast based on the user's current location
- Weather forecasts for areas around Singapore
- Bookmark locations around Singapore
- Weather Reminder Notification

## How to Use the Application

The application requires an active internet connection to retrieve weather data. Most features require an internet connection. 

The application is split into multiple pages. The Home, Search, Map, and Bookmarks Pages can be accessed through the bottom navigation bar, while the Details Page can be accessed by selecting a location.

### Home Page

The Home Page is able to display weather information based on the user's current location. Note that location permissions are required.

Users can:

- View the current weather at their location based on the current hour.
- Select different hours of the day to view hourly weather information.
- Select different dates to view past and forecast weather.
- Refresh the page using the refresh button.
- Set a weather reminder notification.

### Search Page

The Search Page allows users to browse weather information for different locations around Singapore.

Users can:
- Browse the available locations.
- Filter locations based on region.
- Select a location to view its weather information on the details page. 



### Map Page

The Map Page provides a visual way to explore weather conditions around Singapore.

Users can:

- Drag horizontally and vertically to navigate around the map.
- View marked locations around Singapore and their current weather conditions.
- Select a marked location to view its weather information on the Details Page.
- Refresh the page using the refresh button.


### Details Page

The Details Page displays weather information for a selected location.

Users can:

- View the current weather at the selected location based on the current hour.
- Bookmark or remove the selected location using the star icon.
- Select different hours of the day to view hourly weather information.
- Select different dates to view past and forecast weather.
- Refresh the page using the refresh button.

### Bookmarks Page

The Bookmarks Page displays locations that have been saved by the user.

Users can:

- Browse bookmarked locations and view their current temperatures.
- Select a bookmarked location to view its weather information on the Details Page.
- Filter saved locations by region.
- Remove locations from their bookmarks.
- Refresh the page using the refresh button.
